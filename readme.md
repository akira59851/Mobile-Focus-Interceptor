# 移动端优化小工具

主要优化 SillyTavern 移动端的界面与输入体验，部分优化同时适用于桌面端。

## 功能

- **聚焦拦截（仅移动端）**：阻止虚拟键盘在不需要的场景下频繁弹出，只在用户主动点击输入框时才允许键盘出现。
- **键盘粘贴卡顿修复（仅移动端）**：修复虚拟键盘粘贴大量文本时卡顿的问题。
- **Token Counter 卡顿优化（双端适用）**：优化长文本的分词高亮渲染，避免一次性处理大量内容导致页面假死。
- **界面卡顿修复（双端适用）**：修复打开抽屉或弹窗后会触发整页样式重算的问题。移动端最明显的是键盘弹出/收起卡顿；桌面端表现为开合抽屉/弹窗、切换/拖动面板等操作迟缓。
- **外部浮窗键盘布局修复（仅移动端）**：外部浮窗应用（如 WeChat、Discord）呼出键盘时，ST 主界面不再被顶起。

## 使用

安装并启用插件即可，无需额外配置。

如需排查问题，在 `index.js` 顶部将 `MFI_DEBUG` 改为 `true` 开启调试日志。

## 兼容性

仅适用于移动端的功能不会在桌面端加载。

## 更新日志

### [v1.3.0] - 2026-09-10

**[新增]**
- 界面卡顿修复（双端适用）：解决打开抽屉或弹窗后触发整页样式重算导致的持续卡顿问题。
- 外部浮窗键盘布局修复（仅移动端）：外部浮窗应用呼出键盘时 ST 主界面不再被顶起。

**[优化]**
- 控制台降噪：优化控制台日志输出，默认仅保留一条插件加载提示，可通过 `MFI_DEBUG` 开关启用详细日志。

### [v1.2.0] - 2026-08-22

**[新增]**
- Token Counter 分词高亮优化：长文本输入与粘贴可快速响应，首屏限量展示，超出部分通过「继续加载」按钮渐进式分批渲染。

**[优化]**
- 限制 Token Counter 面板中输入框与 Token ID 列表的展示高度，减少滚动路径上的卡顿。
- 插件更名为「移动端优化小工具」，原名为「Mobile Focus Interceptor」。

### [v1.1.0] - 2026-07-30

**[新增]**
- 移动端长文本粘贴卡顿优化：采用全局拦截策略，仅针对长文本生效，不影响日常输入和桌面端；实测 33 万字符可通过键盘快速粘贴完成。

### [v1.0.0] - 2026-05-17

**[新增]**
- 拦截 SillyTavern 自动聚焦：阻止移动端页面在面板切换时反复弹出虚拟键盘，只在用户真正点击输入框时才允许键盘出现。
